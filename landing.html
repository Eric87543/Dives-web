一頁看懂淨資產

淨資產 = 流動資金 ＋ 投資市值 − 負債。美金與加密自動換算台幣，手風琴式分類，每一檔的佔比一目了然。

  • 頂部顯示淨資產與今日漲跌，點一下進走勢圖
  • 流動資金、投資群組、負債分類收合切換
  • 各群組與持倉的今日損益、佔比環圈

走勢與報表，看得見的成長

淨資產與各類別的走勢圖、漲幅與投入分解；年 → 月 → 日層層鑽取的績效報表，配上迷你走勢與累計損益摘要。

  • 全部 / 年初至今 / 自選日期，點擊釘選當日數值
  • 報表頂部：累計損益、投入、市值、未實現、已實現
  • 走勢紀錄跨裝置共用、關閉重開仍保留

完整的交易帳本

每一筆買入的成本、每一筆賣出的已實現損益與報酬率，全部記得清清楚楚。搜尋、依買賣／市場／時間區間篩選，頂部即時統計總投入與總獲利。

  • 買入顯示成本、賣出顯示獲利金額與比例
  • 漏斗面板：買賣類型 · 市場 · 時間區間
  • 買賣可連動現金帳戶，自動扣款 / 存入

隱私，是預設值

資料只存在你的裝置。想跨裝置時，用你自己的 GitHub 私人 Gist 同步 —— 開發者與任何人都看不到。再加上 App 鎖定與一鍵隱藏金額。

  • App 鎖定：PIN · Face ID · 指紋，自動鎖定
  • 一鍵把淨資產與總倉位換成 ✱✱✱✱
  • CSV 備份還原，與 iOS 原生 App 相容
